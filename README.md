# GovernedCredit AI

**Explainable Credit Risk, Model Risk & AI Governance Framework for Financial Institutions**

GovernedCredit AI is an independent portfolio project demonstrating how a financial institution could develop, validate, explain, monitor, and govern a machine-learning credit-risk decision-support system.

## Live portfolio

The public GitHub Pages site provides an executive view of:

- Model Performance
- Explainability
- Responsible AI and Fairness
- Model Risk Validation
- Monitoring and KRIs
- AI Governance

## Executive case study

A concise 3-page executive case study is included for recruiters, interviewers, model-risk teams, Responsible AI teams, and financial-sector leaders.

## What the project demonstrates

**Data Governance -> Model Development -> Calibration -> Explainability -> Fairness -> Model Risk -> Human Oversight -> Monitoring -> AI Governance**

The project connects technical machine-learning work with enterprise financial-sector governance.

## Scope

GovernedCredit AI is a methodological and governance demonstrator.

It is not:

- a production credit decisioning system
- an approved IRB model
- a regulatory one-year PD model
- a Basel compliance certification
- validated for a current EU lending population
